Cómo usarlo

  1. Configura la URL de tu endpoint de inferencia.
  2. Selecciona el modo y añade el prompt.
  3. Adjunta imagen o video si el modo lo requiere.
  4. Pulsa generar para enviar un FormData.

Este HTML no levanta el modelo por sí solo: necesita un backend que acepte la petición y devuelva un video.
